Data Types

📖 Definition

Data Types define the type of value stored in a variable. Python automatically identifies the type of data you store.

💡 Why We Use Data Types

  • To store different kinds of information.
  • To perform operations correctly.
  • To help Python understand the data.
  • To avoid errors in programs.

📝 Syntax

name = "Sriram"
age = 18
height = 5.9
is_student = True

🔍 Syntax Breakdown

  • String (str) → Text values.
  • Integer (int) → Whole numbers.
  • Float (float) → Decimal numbers.
  • Boolean (bool) → True or False values.

📚 Common Python Data Types

Data Type Example
String "Hello"
Integer 100
Float 10.5
Boolean True
List [1,2,3]
Tuple (1,2,3)
Dictionary {"name":"Sriram"}

💡 Explanation

Every value stored in Python belongs to a specific data type. For example, text is stored as a String, whole numbers are stored as Integers, and decimal values are stored as Floats.

Python automatically determines the data type when a value is assigned.

✅ Example

name = "Sriram"
age = 18
height = 5.9
is_student = True

print(type(name))
print(type(age))
print(type(height))
print(type(is_student))

🎯 Output

<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>

Type Casting

📖 Definition

Type Casting is the process of converting one data type into another data type. For example, converting a String into an Integer or an Integer into a Float.

💡 Why We Use Type Casting

  • To perform mathematical operations.
  • To convert user input into numbers.
  • To avoid type-related errors.
  • To make data compatible with our program.

📝 Syntax

int(value)
float(value)
str(value)
bool(value)

🔍 Syntax Breakdown

  • int() → Converts data into Integer.
  • float() → Converts data into Float.
  • str() → Converts data into String.
  • bool() → Converts data into Boolean.

📚 Common Type Casting Functions

Function Example Result
int() int("25") 25
float() float("10.5") 10.5
str() str(100) "100"
bool() bool(1) True

💡 Explanation

Sometimes Python cannot perform operations between different data types. In such situations, we use type casting to convert values into the required type.

This is especially useful when taking input from users because Python treats input as a String by default.

✅ Example 1: String to Integer

age = "18"

age = int(age)

print(age + 2)

🎯 Output

20

✅ Example 2: Integer to String

marks = 95

marks = str(marks)

print("Marks: " + marks)

🎯 Output

Marks: 95

⚠ Common Mistakes

age = "18"

print(age + 5)

This will produce an error because Python cannot add a String and an Integer directly.

✅ Correct Way

age = "18"

age = int(age)

print(age + 5)

🎯 Output

23

🧠 Real World Example

When users enter their age in a registration form, the input is received as a String. We convert it into an Integer to perform calculations. 

age = input("Enter Age: ")

age = int(age)

print(age + 1)

If Statement

📖 Definition

The if statement is used to make decisions in Python. It executes a block of code only when a condition is True.

💡 Why We Use If Statement

  • To make decisions in programs.
  • To check conditions.
  • To control program flow.
  • To create smart applications.

📝 Syntax

if condition:
    # code to execute

🔍 Syntax Breakdown

  • if → Decision making keyword.
  • condition → Expression that returns True or False.
  • : → Indicates the start of the block.
  • Indentation → Code inside the if block must be indented.

💡 How It Works

Python first checks the condition. If the condition is True, the code inside the if block runs. If the condition is False, Python skips the block.

✅ Example 1

age = 18

if age >= 18:
    print("You can vote")

🎯 Output

You can vote

✅ Example 2

marks = 85

if marks >= 35:
    print("Pass")

🎯 Output

Pass

📊 Flow Explanation

Start
  ↓
Check Condition
  ↓
True ? ---- Yes ----> Execute Code
  ↓
 No
  ↓
Skip Code
  ↓
End

⚠ Common Mistake 1

age = 18

    print("Adult")

✅ Correct Way

age = 18

if age >= 18:
    print("Adult")

⚠ Common Mistake 2

age = 18

if age >= 18:
print("Adult")

Error because indentation is missing.

✅ Correct Way

age = 18

    print("Adult")

If Else Statement

📖 Definition

The If Else statement is used when we want Python to choose between two possible actions. If the condition is True, one block runs. If the condition is False, another block runs.

💡 Why We Use If Else

  • To make decisions in programs.
  • To handle True and False situations.
  • To control program flow.
  • To build smart applications.

📝 Syntax

if condition:
    # code if True
else:
    # code if False

🔍 Syntax Breakdown

  • if → Checks the condition.
  • condition → Returns True or False.
  • else → Runs when the condition is False.
  • : → Starts a block of code.
  • Indentation → Required in Python.

💡 How It Works

Python checks the condition first. If it is True, the if block runs. Otherwise, the else block runs. Only one block executes.

✅ Example 1: Voting Eligibility

else:
    print("Fail")

🎯 Output

Pass

📊 Flow Explanation

Start
  ↓
Check Condition
  ↓
True?
 ↓      ↓
Yes      No
 ↓        ↓
If Block  Else Block
 ↓        ↓
    End

Elif Statement

📖 Definition

The elif statement stands for "Else If". It is used when we need to check multiple conditions. If the first condition is False, Python checks the next condition using elif.

💡 Why We Use Elif

  • To check multiple conditions.
  • To avoid writing many separate if statements.
  • To make decision-making easier.
  • To improve code readability.

📝 Syntax

if condition1:
    # code
elif condition2:
    # code
elif condition3:
    # code
else:
    # code

🔍 Syntax Breakdown

  • if → Checks the first condition.
  • elif → Checks another condition if previous condition is False.
  • else → Executes when all conditions are False.
  • : → Starts a code block.
  • Indentation → Required in Python.

💡 How It Works

Python starts from the top. As soon as one condition becomes True, Python executes that block and stops checking the remaining conditions.

marks = 85

if marks >= 90:

elif marks >= 75:

elif marks >= 35:
    print("Grade C")
else:
    print("Fail")

Grade A

if age < 13:

elif age < 18:
    print("Teenager")
elif age < 60:
    print("Adult")
else:
    print("Senior Citizen")

🎯 Output

Adult

Start
  ↓
Check Condition 1
  ↓
True ? → Run Code
  ↓
False
  ↓
Check Condition 2
  ↓
True ? → Run Code
  ↓
False
  ↓
Check Condition 3
  ↓
True ? → Run Code
  ↓
False
  ↓
Else Block
  ↓
End

Nested If Statement

📖 Definition

A Nested If Statement means placing one if statement inside another if statement. It is used when we need to check multiple levels of conditions.

💡 Why We Use Nested If

  • To check multiple conditions step by step.
  • To perform advanced decision making.
  • To create login systems.
  • To create ATM and banking applications.

📝 Syntax

if condition1:
    
    if condition2:
        # code

🔍 Syntax Breakdown

  • Outer If → First condition.
  • Inner If → Second condition.
  • The inner if runs only when the outer if is True.
  • Indentation is very important.

💡 How It Works

Python first checks the outer condition. If it is True, Python enters the outer block. Then Python checks the inner condition. If both conditions are True, the inner block executes.

✅ Example 1: Voting Eligibility

age = 20
citizen = True

if age >= 18:

        print("Eligible To Vote")

🎯 Output

Eligible To Vote

marks = 85
documents = True

if marks >= 75:
    
    if documents:
        print("Admission Approved")

🎯 Output

Admission Approved

📊 Flow Explanation

Start
  ↓
Outer Condition
  ↓
True?
 ↓
Yes
 ↓
Inner Condition
 ↓
True?
 ↓
Yes
 ↓
Execute Code
 ↓
End

⚠ Common Mistake

age = 20

if age >= 18:

if True:
    print("Eligible")

Error because the inner if statement is not properly indented.

✅ Correct Way

age = 20

if age >= 18:

    if True:
        print("Eligible")

For Loop

📖 Definition

A For Loop is used to repeat a block of code multiple times. It is commonly used when we know how many times we want to repeat something or when we want to go through a collection of items.

💡 Why We Use For Loops

  • To process lists, strings, and other collections.
  • To perform repetitive tasks efficiently.
  • To make programs shorter and cleaner.

While Loop

📖 Definition

A While Loop repeatedly executes a block of code as long as a condition remains True. Unlike a For Loop, we usually use a While Loop when we don't know exactly how many times the loop should run.

💡 Why We Use While Loops

  • To repeat tasks until a condition becomes False.
  • To create login systems.
  • To build games and menu-driven programs.
  • To continuously take user input.

📝 Syntax

while condition:
    # code

🔍 Syntax Breakdown

  • while → Loop keyword.
  • condition → Checked before every iteration.
  • : → Starts the loop block.
  • Indentation → Required for loop body.

💡 How It Works

Python checks the condition. If it is True, the loop executes. After execution, Python checks the condition again. The process continues until the condition becomes False.

✅ Example 1: Basic While Loop

count = 1

while count <= 5:
    print(count)
    count += 1

🎯 Output

1
2
3
4

Break Statement

📖 Definition

The Break Statement is used to immediately stop a loop. When Python encounters a break statement, it exits the loop completely and continues with the next line of code after the loop.

💡 Why We Use Break

  • To stop a loop when a condition is met.
  • To improve program performance.
  • To avoid unnecessary iterations.
  • To exit menus and search operations.

📝 Syntax

for item in sequence:

    if condition:
        break

🔍 Syntax Breakdown

  • break → Stops the loop immediately.
  • Works inside both For and While loops.
  • Control moves to the first statement after the loop.

💡 How It Works

Python keeps running the loop until it encounters the break statement. Once break executes, the loop ends immediately.

✅ Example 1: Stop Loop at 5

for i in range(1,11):

    if i == 5:
        break

    print(i)

3
4

numbers = [10, 20, 30, 40, 50]

for num in numbers:

    if num == 30:
        print("Found")
        break

Found

Continue Statement

📖 Definition

The Continue Statement is used to skip the current iteration of a loop and move directly to the next iteration. Unlike Break, Continue does not stop the loop completely.

💡 Why We Use Continue

  • To skip unwanted values.
  • To filter data.
  • To ignore specific conditions.
  • To make loops more efficient.

📝 Syntax

for item in sequence:

    if condition:
        continue

    print(item)

🔍 Syntax Breakdown

  • continue → Skips current iteration.
  • Loop does not stop.
  • Moves directly to the next iteration.
  • Works in both For and While loops.

💡 How It Works

When Python encounters continue, it skips the remaining code inside the current loop iteration and starts the next iteration immediately.

Lists

📖 Definition

A List is a collection used to store multiple values in a single variable. Lists are ordered, changeable (mutable), and allow duplicate values.

💡 Why We Use Lists

  • Store multiple values together.
  • Manage large amounts of data.
  • Access data easily using indexes.
  • Perform operations on groups of items.

📝 Syntax

fruits = ["Apple", "Banana", "Mango"]

🔍 Syntax Breakdown

  • fruits → Variable Name.
  • [] → Represents a List.
  • "Apple" → First Item.
  • "Banana" → Second Item.
  • "Mango" → Third Item.

💡 How Lists Work

Each item inside a list has an index. Indexing starts from 0. 

fruits = ["Apple", "Banana", "Mango"]

Index:
Apple  → 0
Banana → 1
Mango  → 2

✅ Example 1: Create a List

fruits = ["Apple", "Banana", "Mango"]

print(fruits)

🎯 Output

['Apple', 'Banana', 'Mango']

✅ Example 2: Access List Items

fruits = ["Apple", "Banana", "Mango"]

print(fruits[0])
print(fruits[1])

🎯 Output

Apple
Banana

📚 Negative Indexing

Negative indexes start from the end of the list. 

fruits = ["Apple", "Banana", "Mango"]

print(fruits[-1])

🎯 Output

Mango

📚 List Slicing

Slicing allows us to get multiple items from a list. 

numbers = [10,20,30,40,50]

print(numbers[1:4])

🎯 Output

[20, 30, 40]

➕ append() Method

Adds an item at the end of the list. 

fruits = ["Apple", "Banana"]

fruits.append("Mango")

print(fruits)

🎯 Output

['Apple', 'Banana', 'Mango']

➖ remove() Method

Removes a specific item from the list. 

fruits = ["Apple", "Banana", "Mango"]

fruits.remove("Banana")

print(fruits)

🎯 Output

['Apple', 'Mango']

🗑 pop() Method

Removes an item using its index. 

fruits = ["Apple", "Banana", "Mango"]

fruits.pop(1)

print(fruits)

🎯 Output

['Apple', 'Mango']

📏 len() Function

Returns the number of items in a list. 

fruits = ["Apple", "Banana", "Mango"]

print(len(fruits))

🎯 Output

3

🔄 Loop Through a List

fruits = ["Apple", "Banana", "Mango"]

for fruit in fruits:
    print(fruit)

🎯 Output

Apple
Banana
Mango

⚠ Common Mistake

print(fruits[5])

Error because index 5 does not exist.

✅ Correct Way

fruits = ["Apple", "Banana", "Mango"]

print(fruits[2])

print(cart)

Tuples

📖 Definition

A Tuple is a collection used to store multiple values in a single variable. Tuples are ordered and allow duplicate values, but they cannot be changed after creation. This property is called Immutable.

💡 Why We Use Tuples

  • To store fixed data.
  • To improve performance.
  • To prevent accidental modifications.
  • To represent constant values.

📝 Syntax

fruits = ("Apple", "Banana", "Mango")

🔍 Syntax Breakdown

  • fruits → Variable Name.
  • () → Represents a Tuple.
  • "Apple" → First Item.
  • "Banana" → Second Item.
  • "Mango" → Third Item.

💡 How Tuples Work

Each item inside a tuple has an index. Like Lists, indexing starts from 0. However, tuple values cannot be changed after creation. 

fruits = ("Apple", "Banana", "Mango")

Index:
Apple  → 0
Banana → 1
Mango  → 2

✅ Example 1: Create a Tuple

fruits = ("Apple", "Banana", "Mango")

print(fruits)

🎯 Output

('Apple', 'Banana', 'Mango')

✅ Example 2: Access Tuple Items

fruits = ("Apple", "Banana", "Mango")

print(fruits[0])
print(fruits[1])

🎯 Output

Apple
Banana

📚 Negative Indexing

fruits = ("Apple", "Banana", "Mango")

print(fruits[-1])

🎯 Output

Mango

📚 Tuple Slicing

numbers = (10,20,30,40,50)

print(numbers[1:4])

🎯 Output

(20, 30, 40)

📦 Tuple Packing

Packing means storing multiple values into a tuple. 

student = ("Sriram", 18, "Cyber Security")

📤 Tuple Unpacking

Unpacking means extracting tuple values into separate variables. 

student = ("Sriram", 18, "Cyber Security")

print(branch)

Sets

📖 Definition

A Set is a collection used to store multiple values in a single variable. Sets do not allow duplicate values and are unordered.

💡 Why We Use Sets

  • To store unique values.
  • To remove duplicates automatically.
  • To perform mathematical set operations.
  • To improve searching performance.

📝 Syntax

fruits = {"Apple", "Banana", "Mango"}

🔍 Syntax Breakdown

  • fruits → Variable Name.
  • {} → Represents a Set.
  • Values inside a set must be separated by commas.
  • Duplicate values are automatically removed.

💡 How Sets Work

Sets store only unique values. If duplicate values are added, Python automatically removes them.

✅ Example 1: Duplicate Removal

numbers = {1, 2, 3, 2, 1, 4}

print(numbers)

🎯 Output

{1, 2, 3, 4}

➕ add() Method

Used to add a new value into a set. 

fruits = {"Apple", "Banana"}

fruits.add("Mango")

print(fruits)

🎯 Output

{'Apple', 'Banana', 'Mango'}

➖ remove() Method

Used to remove a value from a set. 

fruits = {"Apple", "Banana", "Mango"}

fruits.remove("Banana")

print(fruits)

🎯 Output

{'Apple', 'Mango'}

📏 len() Function

fruits = {"Apple", "Banana", "Mango"}

print(len(fruits))

🎯 Output

3

🔄 Loop Through a Set

fruits = {"Apple", "Banana", "Mango"}

for fruit in fruits:
    print(fruit)

🎯 Output

Apple
Banana
Mango

🤝 Union Operation

Union combines all unique values from two sets. 

set1 = {1, 2, 3}
set2 = {3, 4, 5}

result = set1.union(set2)

print(result)

🎯 Output

{1, 2, 3, 4, 5}

🎯 Intersection Operation

Intersection returns common values between sets. 

set1 = {1, 2, 3}
set2 = {2, 3, 4}

result = set1.intersection(set2)

print(result)

🎯 Output

{2, 3}

➖ Difference Operation

Difference returns values present in the first set but not in the second set. 

set1 = {1, 2, 3}
set2 = {2, 3, 4}

print(set1.difference(set2))

🎯 Output

{1}

⚠ Common Mistake

fruits = {"Apple", "Banana"}

print(fruits[0])

Error because Sets do not support indexing. Sets are unordered collections.

✅ Correct Way

for fruit in fruits:
    print(fruit)
